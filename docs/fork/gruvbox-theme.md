# Gruvbox Material workspace theme

A "Gruvbox" workspace theme in Settings › Appearance, with Gruvbox Material file icons in the explorer and editor syntax colours matching the VS Code theme while it is active. (PRs #6, #43)

## Fork files
- `src/features/settings/model/gruvboxTheme.ts` — `GRUVBOX_THEME` definition
- `src/features/files/ui/gruvboxIcons.ts`, `src/features/files/model/gruvboxIcons.json` — icon set, generated by `scripts/generate-gruvbox-icons.mjs`
- `src/styles/gruvboxTheme.css` — `--syntax-*` overrides keyed on `data-workspace-theme`
- `src/features/files/editor/syntaxRefinements.ts` — `SYNTAX_REFINEMENTS`, extra highlight tags

## Upstream hooks
- `src/features/settings/model/workspaceThemes.ts` — `"gruvbox"` in `WorkspaceThemeId`, `GRUVBOX_THEME` in `WORKSPACE_THEMES`
- `src/features/settings/model/appearance.ts` — `subscribeWorkspaceTheme`, `getAppliedWorkspaceTheme`, listeners fired in `applyWorkspaceTheme`; `root.dataset.workspaceTheme` set there
- `src/main.tsx` — `import "./styles/gruvboxTheme.css"`
- `src/features/files/editor/editorLanguage.ts` — `...SYNTAX_REFINEMENTS` in both highlight style lists
- `src/features/files/editor/editorChrome.ts` — `var(--syntax-plain, …)` fallback for the plain text colour
- `src/features/files/editor/syntaxTokens.test.ts` — `KEYWORD` expects `var(--syntax-storage, var(--syntax-keyword))`
- `src/features/settings/model/settings.ts` — `gruvbox` keyword in the theme `SETTINGS_INDEX` entry
- `src/features/files/ui/FileTypeIcon.tsx` — `gruvboxSvg` tried before `icons.getIconSvg`
- `NOTICE` — gruvbox-material-icons attribution
